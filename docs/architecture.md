# 实现结构

```text
每个原媒体 → 复制到独立目录 → FFmpeg 切块 → 阿里云 ASR → 同名 SRT/TXT
该媒体的文本 → 关键词命中与上下文 → 该媒体目录内的 CSV/XLSX
```

media 负责文件复制、同名避让、批量扫描与恢复；storage 的 MediaItem 对应一份媒体目录，状态位于 .corpus 中，通过原子 JSON 与锁保护。

inputs 解析 SRT/TXT/CSV/XLSX，并保存与媒体同名的转写文件。关联输入不追加重复文本，替换前保留输出备份。transcription 识别媒体副本，支持限速、停止和逐块断点；一批多个媒体共用请求限速时钟。providers 只保留阿里云接口。

search 用任意字面关键词生成逐次命中、来源媒体和上下文，替换文本使结果失效。exports 读取一致的媒体状态快照，表格在媒体目录顶层，JSON 和完成标记在 .corpus/exports。gui 为单窗口媒体列表及按顺序排列的两个操作区域；cli 直接接受媒体路径。

ui 使用原生 Tk 绘制卡片、按钮和矢量图标，gui 负责选择媒体与后台任务交互；任务消息回到主线程更新控件。tkinterdnd2 提供文件拖放，加载失败则保留按钮添加方式。任务日志在独立窗口查看，运行中禁用设置与检索输入。

媒体复制保留大小和修改时间；来源身份包含原路径、文件属性，内部断点依赖媒体属性和识别设置。恢复时使用相对媒体路径，因此整体移动目录仍可继续。FFmpeg 使用参数数组、禁用 shell，Windows 隐藏辅助进程窗口。
