# 使用说明

## 添加与选择媒体

保存位置留空时，每个媒体在原文件旁生成同名文件夹；指定位置时，在该位置生成各媒体的同名文件夹。媒体通过流式复制保存，原文件保留。不同原路径的同名文件用括号编号区分，已有无关文件夹也会避让。

支持 mp4/mkv/mov/avi/flv/wmv/mpg/webm 和 mp3/wav/flac/m4a/ogg。“批量添加文件夹”扫描子目录，忽略运行缓存和虚拟环境。

可将媒体或文件夹直接拖入左侧媒体列表。文件名和状态列标题可排序，列表复选框用于选择文件，表头复选框切换全选。

左侧列表支持 Ctrl/Shift 多选。右侧的转写、检索作用于当前所选媒体；全选可批量处理。“移出列表”只影响当前窗口中的列表，文件夹仍保留。输出位置的修改只影响随后添加的新媒体。

再次使用时，添加已整理文件夹里的媒体文件；已保存的文本和检索结果会恢复。也可再次添加原文件，但须选择之前使用的保存位置。

## 转写与停止

阿里云设置里填写 API Key、模型、服务地址和 FFmpeg。语言留空自动识别；指定语言使用模型支持的代码，例如 zh/en/yue。

默认 60 秒分块，允许 5–120 秒。本地音频转换为 16kHz 单声道 WAV，逐块发送，成功块及时写断点。失败后继续任务会复用相同媒体、分段秒数、模型、地址、语言配置下成功的块。已经具备文本的媒体跳过 ASR。

复制停止后会清理本次临时文件，重新添加可完成复制。转写停止会等待当前网络请求返回或超时后停止，继续时复用断点。字幕时间是分块时间，不是逐句对齐。

## 关联已有文本

同名 SRT/TXT 会在添加原媒体时自动关联，SRT 优先。可通过“使用已有字幕 / TXT”关联任意文本；此操作只针对一个选中媒体。

- SRT 按字幕段解析，并生成同名 TXT。
- TXT 按非空行解析，保留原始行号，没有音频时间。
- CSV 必须有表头；XLSX 每个工作表第一行是表头，读取所有工作表。
- 表格文本列任选 `文本`、`内容`、`text`、`transcript`、`sentence`、`台词`、`语料`。
- 可选开始列 `开始时间/start/start_time`、结束列 `结束时间/end/end_time`，格式 HH:MM:SS,mmm 或 HH:MM:SS.mmm。无时间列可为空，其他字段保留在导出 JSON 中。

关联新文本会替换当前检索文本而不追加重复段落。已有生成文件备份到 .corpus/history/。新文本全部有时间才生成 SRT；无时间的 TXT 不保留已经失效的旧 SRT。输入格式错误时保留此前的文本和检索结果。

## 检索与导出

关键词用换行或逗号分隔，短语内的空格保留。包含逗号的短语可用 CLI --keywords 的单个字符串参数查询。按字面查找，不执行正则；中文不分词，英文可忽略大小写。没有命中时也可导出只有表头的表格。

关键词输入框显示非空行数；右下角展开图标可打开较大的编辑窗口。界面默认忽略英文大小写，可取消勾选。点击结果行，在表格下方查看命中上下文；Esc 收起上下文。

“检索预览”保存检索结果，不生成表格；“检索并导出表格”给每个媒体单独生成 CSV 和 XLSX。勾选“仅 CSV”可不安装 Excel 导出库。多选媒体时预览合并显示所选媒体的结果，导出仍逐文件保存。预览最多 500 行，导出包含全部命中。

可选繁简转换，需安装 OpenCC。查询与文本一同转换，原文保留。“起始字符位置”从 0 开始，范围左闭右开，指向“文本”列而非原文列。

底部显示当前任务状态；处理过程使用滚动进度条，完成时显示 100%，复制和转写可停止。“日志”打开单独窗口查看各媒体处理详情。

## 保存与恢复

媒体、同名 SRT/TXT、按日期命名的检索表格位于媒体文件夹顶层。运行状态在 .corpus/ 中：

- state.json 与 state.previous.json：当前及上次写入前的文本、检索记录和媒体信息。
- jobs/：本地音频切块和断点。
- inputs/：关联文本的原始快照。
- history/：替换文本前的生成文件备份。
- exports/：每次导出的完整 JSON 和完成标记。

文件夹可以整体移动，程序读取内部的媒体副本，状态路径是相对路径。媒体是否变化按大小和修改时间判断，不计算大视频的完整哈希。若修改了媒体副本，请在新的位置添加修改后的媒体。

write.lock 和 task.lock 用于防止重复任务和写入冲突。正常结束自动清理；程序崩溃后若存在遗留锁，请先确认使用该媒体文件夹的进程全部结束，再移除相应锁。state.previous.json 可用于恢复上次状态。

0.3 及以前的集中语料目录可保留。使用新界面添加原媒体，再通过“使用已有字幕 / TXT”关联旧的转写输出即可；新版本不会自动删除或改写旧目录。
