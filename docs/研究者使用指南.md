# 语言学与方言研究使用建议

Corpus Collector 用于语料收集和整理：将媒体转写为文本，检索指定词汇或短语，生成带来源和上下文的表格。可处理访谈、田野录音、口语视频和课堂材料。

## 方言材料如何转写

默认调用阿里云 qwen3-asr-flash。按照 [阿里云模型说明](https://help.aliyun.com/zh/model-studio/asr-model)，中文识别范围包括普通话、四川话、闽南语、吴语和粤语；实际可用范围取决于模型版本。

阿里云 ASR 设置中的“语言”留空时自动识别。已知材料语种时，可指定：

| 材料 | 语言设置 |
| --- | --- |
| 普通话、四川话、闽南语、吴语 | zh |
| 粤语 | yue |
| 英语 | en |
| 混合语种或不确定 | 留空 |

这些取值对应当前默认模型的 [官方接口文档](https://help.aliyun.com/zh/model-studio/qwen-asr-api-reference)。不要将具体方言地名直接填入语言设置；支持的语言代码不等于所有方言名称。

先使用一小段具有代表性的材料检验识别结果，再处理整批录音。识别结果作为初稿，研究者应回听核对方言用字、语气词、专名和说话重叠。需要音标、声调或逐句对齐时，应另行进行人工转写或专门的语音分析。

## 从文本汇集研究例句

1. 将每个媒体添加到左侧列表，生成各自的整理文件夹。
2. 转写，或为单个媒体关联已有 SRT/TXT。已有同名 SRT/TXT 会在添加时自动读取。
3. 输入目标词汇或固定短语。每行一个，也可用逗号分隔；查询按字面匹配。
4. 先点击“检索预览”，检查命中和上下文，再点击“检索并导出表格”。
5. 在每个媒体自己的文件夹中找到 CSV/XLSX，回听核对后继续人工编码或分析。

同一段中的重复出现分别成行；命中表保留来源、时间、左右上下文和原始文本。未命中的词不产生记录。多选文件时界面合并预览，导出仍分别保存。

检索对当前保存的转写文本进行匹配。ASR 漏字、同音误写及不同方言用字都会影响检索，未检索到不能直接解释为原始录音中没有该表达。若需修正，编辑对应 TXT，随后通过“使用已有字幕 / TXT”重新读取并检索；TXT 没有时间信息，若需保留时间应修订并读取 SRT。

## 时间与保存

SRT 时间表示固定音频块的起止，不是词或句的准确边界。默认分块 60 秒，可在 ASR 设置中调整为 5–120 秒。表格时间用于定位回听，不宜直接用作语速、音段时长等声学测量。

每个媒体的文件夹保存媒体副本、SRT、TXT、导出表格及 .corpus 状态。导出表格以新的文件名保存；整个文件夹可以移动，再添加其中的媒体即可继续。

转写时音频块发送到阿里云，语料文本的检索、繁简转换和导出在本地执行。涉及受访者信息的材料，请按研究使用条件决定是否使用云端识别；已有人工转写可直接在本地检索。
